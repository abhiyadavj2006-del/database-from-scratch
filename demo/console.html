minidb — live SQL console

A real, working database in your browser: the same SQL as the Python minidb, re-implemented in pure JavaScript (minidb.js — no server, no build step, no CDN, no account). Type a query below and run it. Your data is saved in this browser (localStorage), so it survives a reload.

What runs here — and what does not

Works: CREATE TABLE / DROP TABLE, CREATE INDEX, INSERT (single + multi-row, with/without column list), SELECT with WHERE (= != < > <= >=, AND, OR, IS [NOT] NULL), ORDER BY … ASC/DESC, LIMIT / OFFSET, UPDATE, DELETE, SHOW TABLES, DESCRIBE, EXPLAIN SELECT …, BEGIN / COMMIT / ROLLBACK, PRIMARY KEY / NOT NULL / UNIQUE, NULL values, types INT TEXT FLOAT BOOL (+ INTEGER VARCHAR REAL BOOLEAN aliases). Dot-commands: .tables, .schema <table>, .help.

Not here: no JOINs, GROUP BY, aggregates or subqueries (same as the Python version); no TCP server; persistence is localStorage in this browser instead of the on-disk 4 KiB page file — the Python minidb is the one with real B-trees, a journal and crash recovery. Plans still say INDEX SCAN / FULL TABLE SCAN exactly like the Python planner.
